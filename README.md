# URBAI website

A static, GitHub Pages-ready website presenting the results of the URBAI — Urban Artificial Intelligence project.

## Publish on GitHub Pages

1. Upload the contents of this folder to the root of a GitHub repository.
2. In **Settings → Pages**, select **Deploy from a branch**.
3. Select the `main` branch and the `/ (root)` folder.
4. If you use a custom domain, add it in the Pages settings (and optionally create a `CNAME` file).

No build step or external JavaScript library is required.

## Before publication

- Replace `https://example.org/urbai-publications.bib` in `publications.html` if a project BibTeX file is available, or remove the button.
- Add any missing project identifiers (PRIN code, CUP, exact start/end dates, total funding) once verified.
- Review whether every listed output should be formally attributed to URBAI.
- Replace or expand the contact details if needed.
